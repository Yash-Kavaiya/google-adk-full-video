WHAT THIS VIDEO IS
Agent Development Kit (ADK) is Google's open-source agent framework. It is available in Python, TypeScript, Go, Java, and Kotlin. The documented goal is production agents, not prototypes. You start with a model, an instruction, and tools, then grow into multi-agent workflows, graph routing, evaluation, and cloud deployment.

The briefing is source-grounded against first-party ADK documentation checked on 3 September 2026 at google.github.io/adk-docs.

WHAT YOU WILL LEARN
What ADK is: an open-source, multi-language runtime that treats context like source code rather than an overflowing paste buffer.

Core primitives: LlmAgent and workflow agents, Tools, Callbacks, Session, State, Memory, Artifacts, Events, and the Runner.

Build and run: Python 3.10+, pip install google-adk, adk create, a required root_agent in agent.py, adk run, and adk web. The docs warn that ADK Web is for development and debugging, not production.

Tools and skills: tools execute developer-defined logic while the model reasons, selects, and invokes. Function tools, MCP, OpenAPI, AgentTool, confirmations, and experimental on-demand Skills.

Workflows and ADK 2.0: Sequential, Parallel, and Loop templates; graph nodes and edges; dynamic code-driven flow; collaborative coordinators. Python ADK 2.0 GA is 19 May 2026. Treat a 1.x upgrade as a migration.

Context and memory: Session State is this thread. Memory is a searchable long-term archive. In-memory backends are for local tests. Compaction filters, summarizes, and lazy-loads.

Runtime, deploy, evaluate: CLI, web, API server, ambient agents; Agent Runtime, Cloud Run, GKE, or any container. Score both the tool trajectory and the final answer.

Safety and A2A: identity, guardrails, callbacks, sandboxed code, VPC-SC, local sub-agents versus remote A2A contracts. Production auth uses ADC or a service account, never committed keys.
